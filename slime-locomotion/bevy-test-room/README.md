# Arcane Meadow (Bevy test room)

Embedded read-only visual test hosted inside ArcaneVR's Test Room page. Its rendering helper starts hidden with `--embedded`, is reparented into the native Rust application, resizes to the panel, hides on other pages, and exits with its parent. Sensors remain owned by the ArcaneVR receiver. Inline controls send pause/resume/reset/quit through owned stdin. No second user-facing window is required.

Space pauses locally; R resets the field, rear view and local forward reference; J previews a jump; left-drag orbits the camera. Inline Calibrate in the parent starts the upright countdown. The renderer never sends commands to ArcaneVR or opens the tracker UDP port. It pauses for stale snapshots, stale torso, missing calibration, armed output, or input not ready. It uses movement preview and calibrated chest heading. Tilt + steps scales tilt input by step speed; chest heading + steps travels forward by step speed.

The current character is the orange Quaternius mannequin with purple joints shown in the supplied article. Its official CC0 Standard GLB and original materials are preserved. It includes authored idle, walk, jog, sprint, crouch and jump clips. A rising jump input starts a visible jump arc and the start/loop/land sequence. Physical jumps use the configured ArcaneVR jump preview; J is explicitly a local animation test. See assets/CHARACTER-SOURCE.txt and LICENSE-character.txt.

The free Standard file does not contain the article's Pro eight-direction jogs. Backward travel reverses its walk clip; strafing keeps the requested facing/travel but uses a labeled forward-walk fallback. This is not claimed to reproduce those unavailable authored Pro clips. The original article, videos and research evidence are retained under references/original-twin-stick.

The movement/facing basis and relative directional selection follow Doce Fernandes's linked explanation: https://doce.sh/blog/twin-stick-animations . That page supplies vector-math snippets, not a full application or its paid eight-direction animation assets. This is an adaptation of those snippets to live chest input, not a recovered copy of an unavailable full project. Heading remains independent of travel, including turning in place. The ground and its markings remain fixed in world space; the camera uses a movement dead-zone so displacement is visible.

Verification: cargo +1.95.0 test --release; python tests/runtime_qa.py. The latter uses strict HTTP Host validation and drives the actual Bevy renderer, checking translated distance, all cardinal animation states, a full stationary turn, world-fixed ground, and inline pause/reset commands. Native embedding QA additionally verifies Windows parent HWND, WS_CHILD style, actual bounds after resize, page hide, and return to the Test Room. Use --seconds N, --screenshot path and --qa-report path for bounded app-owned renderer QA. A separate opt-in test checks the real ArcaneVR receiver on port 8811.
